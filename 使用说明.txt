《丰裕之角》桌宠·麟 —— 使用说明（1 分钟上手）

【第零步】先把「原声曲库」放到 exe 旁边（只需一次）
   1. 把「原声曲库.zip」解压到 exe 同级的 music 文件夹里
      （解压完应该是 …\music\原声\ 里面躺着 78 首歌；
        放 music 根目录、或者 exe 旁边单独的「原声」文件夹，麟也认）
   2. 不放也能启动：只是曲库空着，听不了内置原声；启动几秒后麟会在
      气泡里提醒你「曲库好像还没搬过来（找到 x / y 首）」，输入 #音乐
      也会告诉你该放哪儿
   3. 以后升级只覆盖 LinDesktopPet.exe 就行，曲库不用再下一次
      （所以更新包从 620MB 瘦到约 115MB；曲库包约 528MB，只下这一次）

【第一步】双击 LinDesktopPet.exe
   - 若 Windows 提示"已保护你的电脑"：点「更多信息」→「仍要运行」
     （这是没签名的正常提示，不是病毒）

【第二步】（可选）配置 AI 接口，让麟接入大模型
   1. 右键桌宠 → 🔌 API 管理：支持 DeepSeek / OpenAI / Kimi / 通义 /
      智谱 / 本地 Ollama 等，可一键切换和测试
   2. 填入自己的 API Key（以 sk- 开头），保存后即可 AI 对话
   （不配置也完全可用：麟会以离线保底模式陪你，聊天照常）

【第三步】麟出现在桌面右下角，开聊！
   - 底部输入框打字，回车发送
   - 想加自己的歌：右键 → 🧰 工具 → 🎵 音乐播放器 → 「📥 导入音乐」
     （可以选音频，也可以直接选 zip 压缩包，麟会自动解压进曲库），
     或者干脆把音频 / zip 压缩包 / 整个文件夹拖进播放器面板。
   - 右键桌宠看全部功能：喂食 / 商城 / 猜拳 / 专注 / 日程 / 传送门…
   - 右键 → 🧠 心理陪伴：记录情绪 / 心理评测 / 评测历史 / 情绪统计 / 暖心寄语 / 危机支持
     （也可直接输入 #情绪 快速记录，或 #评测 做一次心理自评；
      评测共 16 套本地量表：症状筛查（PHQ-9/GAD-7/SCL-90/SDS/SAS/BDC）、
      人格性格（MBTI/气质/16PF/EPQ/EPQ-RSC）、专项量表
      （PSS/BPNS/IPIP-EIS/情绪稳定性/SCCS），全部离线计分；
      情绪数据存本地 mood.json，评测数据存本地 assessment.json，都不上传）
   - 输入 #帮助 看隐藏指令
   - 21:00~07:00 麟会睡觉（照样回复你，只是迷迷糊糊；睡着时音乐照放、
     不停—— 播放器是麟房间的音响嘛）
   - 只开一只麟：双击几次 exe 也不会多开，第二下只是把麟叫到最前面

【从旧版升级过来】
   - 歌单、分类夹、我喜欢的音乐、回收站、记忆、好感、设置都在 exe 旁边的
     json 文件和 playlist 文件夹里，覆盖新 exe 不会丢
   - 曲库是这一版才开始外置的：旧的 620MB exe 里那批歌不会自动搬出来，
     解压一次「原声曲库.zip」就好，旧 exe 可以直接删掉

【小提示】
   - 没有 Key 也能聊天（离线模式）；联网+Key 才能获得完整 AI 对话
   - Key 保存在 exe 旁边的 api_config.json（旧版 api_key.txt 会自动迁移）
   - 桌宠底部状态行从左到右：好感度 / 天气 / 接入状态（AI 在线 / 离线模式）；
     专注时钟开启后倒计时会顶替好感度和天气显示，互不遮挡
   - 宠物缩放低于 70% 时好感度条自动隐藏（调大宠物即恢复）
   - 麟每天 23:50 自动把对话写成记忆日志（memory_log 文件夹），
     右键 → 📒 记忆日志 / 🧠 记忆回顾 可以查看；商城「回忆相册」可随时手动归档
   - 曲库包被误删了：重新解压一次就恢复（歌单里的记录不会丢）
   - 导入的歌放在 exe 旁边的 music 文件夹（别放进「原声」里），升级换 exe
     也不会丢；同一首导两遍不会重复，rar / 7z 打不开会提示你先解压
   - 把歌拖进「🗑 彻底删除」只是从曲库屏蔽内置原声，曲库包里的文件不会被删
   - 想关闭：右键 → 退出桌宠
   - 若被杀毒软件拦截，请添加信任（PyInstaller 打包程序常被误报）
